# Spotify-Clone
Spotify Clone : A responsive Spotify Clone built using HTML and CSS, inspired by Spotify's modern music streaming interface. The project recreates the Spotify-style sidebar, navigation bar, music cards, featured charts, album section, and bottom music player with playback and volume controls

### Features

* Spotify-inspired responsive UI
* Sidebar navigation and library section
* Recently Played, Trending, and Featured Charts sections
* Album and song information
* Music player with playback controls
* Progress and volume sliders
* Font Awesome icons
* Google Fonts integration

### Technologies Used

* HTML5
* CSS3
* Font Awesome
* Google Fonts

This project was created as a **frontend web development practice project** to improve HTML, CSS, layout, and responsive UI design skills.
